# Rayeq Ecosystem

هذا المستودع يحتوي على المصدر المرفق لمنظومة Rayeq:

- `rayeq/` — تطبيق Rayeq الرئيسي ومكتبة الإضافات.
- `rayeq-admin/` — تطبيق الإدارة.
- `rayeq-server/` — كود الخادم.

## حالة ملفات APK

الأرشيف الأصلي `rayeq-ecosystem-v1.0.0.zip` لم يتضمن أي ملفات `.apk` أو `.aab`؛ لذلك لا توجد حاليًا ملفات قابلة للتثبيت أو أحجام APK يمكن حسابها من الأرشيف. الملفات الموجودة هي شيفرة المصدر فقط.

لبناء APK، يلزم Android SDK وGradle، كما يلزم إعداد `RAYEQ_SERVER_URL` لتطبيق الإدارة. ولإصدار نسخة موقعة، يجب توفير ملف keystore وكلمات المرور خارج المستودع وعدم رفعها إلى GitHub.

## ملاحظات أمنية

لا تضع مفاتيح API أو كلمات مرور أو ملفات keystore داخل المستودع. استخدم متغيرات البيئة أو أسرار GitHub Actions عند إعداد البناء.
