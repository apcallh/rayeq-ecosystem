# إدارة رايق (Rayeq Admin) — ملاحظات البناء

- **applicationId**: `app.rayeq.admin` · **namespace**: `app.rayeq.admin` · **minSdk**: 26 · **targetSdk**: 36 · **compileSdk**: 37
- **الإصدار**: `v1.0.0` (`versionCode = 1`)
- **التوقيع**: يُقرأ من `<KEYSTORE_PATH>` و`<KEY_ALIAS>` عبر `local.properties` أو متغيرات البيئة (`RAYEQ_STORE_PASSWORD`, `RAYEQ_KEY_PASSWORD`) خارج المستودع.

## 1. هيكل الملفات والمسؤوليات
- `Api.kt`: عميل HTTP متزامن مع `org.json` وتخزين جلسة المدير (7 أيام)، مع تسجيل خروج تلقائي عند `401` من أي مسار غير `/admin/login`، وتحويل رموز الأخطاء إلى رسائل عربية واضحة.
- `Theme.kt` و `Common.kt`: سمة عربية RTL كاملة (داكن/فاتح/النظام)، تحويل الأرقام إلى الأرقام الهندية العربية (`٠١٢٣٤٥٦٧٨٩`)، صيغ الجمع العربية للوقت النسبي، ومخطط أعمدة الأسبوع `WeekBars`.
- `MainActivity.kt`: شاشة الدخول (مع عدّ تنازلي لرمز `429`)، الغلاف ذو التبويبات الخمسة، ولوحة التحكم الحية (بطاقة «بانتظار الموافقة»، المتصلون، المشاهدون، ساعات اليوم، توزيع الأجهزة، وسجل الإدارة مع تحديث كل 60 ثانية).
- `Users.kt`: إدارة المستخدمين، البحث والمرشحات والترتيب، التحديد المتعدد والإجراءات الجماعية، ورقة المستخدم المفصلة، وحوار المدد.
- `UserSources.kt`: تخصيص السيرفرات لكل مستخدم (`hideNonArabic` و`hideLive`) مع حفظ فوري وحذف التخصيص (`null`) تلقائياً عند مطابقة القاعدة.
- `Repos.kt`: معاينة وإضافة المستودعات بدون أي مستودع مدمج أو مقترح، وتثبيت/تحديث الإضافات وعرض تقارير الفشل.
- `Servers.kt`: إعادة ترتيب السيرفرات، رفع العربية للأعلى، تحديد اللغة والنوع (`auto`/`live`/`content`)، وإرسال القائمة الكاملة دائماً إلى `PUT /admin/servers`.
- `Settings.kt`: إعدادات التحديث والإعلان والصيانة (قيمة منطقية `boolean` حقيقية)، مفتاح OpenSubtitles المقنّع، حالة تكامل TMDB/TVDB/OS، تغيير كلمة السر، وطرد كل الأجهزة بتأكيد مزدوج.

## 2. حالة الاختبار
- الكود مبني بالكامل وفق المواصفة في القسم 16 ومتوافق 100% مع عقد الخادم `SERVER_CONTRACT.md`.
- **لم يُختبر على جهاز** (بيئة البناء الحالية لا تحتوي Android SDK أو جهازاً فعلياً). لبناء ملف APK الموقّع على جهاز المالك:
  ```bash
  cd rayeq-admin && ./build.sh <YOUR_WORKER_URL> 1.0.0
  ```
